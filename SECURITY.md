# 🛡️ Security Policy — PetSewa Platform

## Supported Versions

The following versions of the **PetSewa Platform** are currently supported with active security updates:

| Version | Supported          |
| ------- | ------------------ |
| v2.x    | :white_check_mark: |
| v1.x    | :x:                |

## Reporting a Vulnerability

The PetSewa engineering team takes the security of user data, payment transactions, and provider operations extremely seriously.

If you discover a security vulnerability within the PetSewa platform (NestJS backend, Flutter app, or cloud integrations), please follow these guidelines:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Contact the **PetSewa-India** repository administrators directly.
3. Include details of the vulnerability:

   - Affected service/module (e.g. Auth, Booking, Payment, Notifications)
   - Step-by-step reproduction steps
   - Potential impact
4. The engineering team will acknowledge receipt of your report within 24 hours and provide an estimated resolution timeline.

Thank you for helping keep the PetSewa ecosystem safe!
